## Description
Resolves #1189

This PR addresses the inconsistent validation error styling across the authentication and task creation forms. It introduces a single, reusable "FormError" component to ensure a consistent, standardized user experience when displaying form errors.

## Related Issue
Closes #1189

## Changes Made
- **New Component**: Created "frontend/src/components/common/FormError.jsx" with consistent spacing, borders, background, text color, and an error icon.
- **Login Form**: Refactored "frontend/src/pages/Login.jsx" to replace raw HTML error blocks with the new "<FormError />" component.
- **Signup Form**: Refactored "frontend/src/pages/Signup.jsx" to use the "<FormError />" component for both the main error message and all individual field validation errors.
- **Task Form**: Refactored "frontend/src/components/Task/TaskFormModal.jsx" to replace its raw error block with the "<FormError />" component.
